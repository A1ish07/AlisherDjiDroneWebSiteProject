# Alisher WEB Technologies Web Site Project


## What the product is
My project demonstrates the fundamentals of HTML and CSS through practical tasks including a personal webpage, a simple layout, a tribute page, and a styled table with form. It showcases the use of selectors, colors, fonts, margins, padding, and borders to organize content visually. All tasks are completed and published online via GitHub Pages.




## 📂 Project Structure

| Task | Description | Files |
|------|-------------|-------|
| **Task 1** | Personal webpage about Drone | `DjiDroneALisher.html`, `DjiDroneALisherStyles.css` |
| **Task 2** | Simple webpage layout using `<div>`, positioning and navigation| `task2.html`, `task2.css` |
| **Task 3** | Tribute page for Hifumi Abe🥋 | `task3.html`, `task3.css` |
| **Task 4** | Table and Form styling | `task4.html`, `task4.css` |
